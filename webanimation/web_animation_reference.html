Technique 01 Scroll-Triggered Reveals Elements fade and slide in as they enter the viewport
✦

Intersection Observer

Use the native IntersectionObserver API to detect when elements enter the viewport. Add an "active" class to trigger CSS transitions.

◈

CSS Transitions

Define initial state (opacity: 0, transform: translateY) and final state (opacity: 1, transform: none). Let CSS handle the interpolation.

◇

Stagger Delays

Use transition-delay on child elements to create a cascading reveal effect. Increases visual rhythm and perceived performance.

Parallax Layer

Technique 03 - 3D Hover Cards

Cards lift and rotate on hover using CSS 3D transforms. Perspective is set on the parent container.

🎨

preserve-3d

Set transform-style: preserve-3d on parent and child elements. This allows nested 3D transforms to compound correctly.

🔮

perspective

Apply perspective: 1000px to the parent container. Lower values = more dramatic 3D effect. Higher = subtler.

✨

rotateX / rotateY

On hover, apply rotateX(5deg) and translateY(-10px). Combine with box-shadow for realistic depth perception.

Technique 04 - Staggered Grid

Grid items animate in one by one with increasing delays. Creates a wave-like entrance effect.
